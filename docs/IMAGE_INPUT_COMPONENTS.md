# Image and input components (preview)

- ImageViewer: `src`/ `alt`, zoom 25–300, rotation in 90-degree increments. Composes Image, Slider, Button, ScrollArea and Icon. `cu-input` and `cu-change` report zoom/rotation; `cu-action` reports image load state. Scroll to inspect enlarged images. No file picker, editing or gesture zoom yet.
- TransferList: set `items` to objects with unique nonempty string values, labels and optional disabled flags; set `value` to selected values. Search separately in each list, move a selected item or all filtered enabled items. Disabled items cannot be moved by actions. Emits `cu-change` with selected values in input order. Not form-associated; use the change event to submit selections in the application.
- CurrencyInput: extends NumberField; `currency` (default USD), `locale` (default en-US), inherited numeric input and form properties. `formattedValue` gives localized display text; `value` remains a numeric string. Default step derives from currency fraction digits unless specified. Invalid locale/currency formatting yields an empty summary. Does not convert currencies or guarantee exact decimal arithmetic.
- MaskedInput: extends TextField; `mask` supports # (ASCII digits), A (ASCII letters), * (ASCII alphanumeric), and other characters as literals. `value` is the formatted value; `rawValue` contains matched token characters. Incomplete nonempty input is validated using the generated pattern; use required for empty-value validation. Basic paste and caret handling; complex IME, escaping mask tokens and separator-deletion behavior need browser review.

All are experimental Web Components with standalone exports, React adapters and direct Vue/Svelte property bindings. Browser and accessibility acceptance remains required.
