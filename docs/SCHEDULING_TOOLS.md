# Scheduling tools (preview)

**Scheduler** composes Calendar, DatePicker, TimePicker, TextField, Button, Timeline and EmptyState. Set date to YYYY-MM-DD and events to an array of objects containing unique string id, title, date, start and end (HH:mm, 24-hour local wall-clock time), plus optional description. Only same-day timed events with end > start are accepted. Invalid entries and duplicates are ignored. The default date is the local current date. Calendar or date picker changes emit cu-change with value/date. Add/remove actions emit cu-action with action, item and the new events array. addEvent(item) and removeEvent(id) return booleans. readonly prevents mutation via actions but allows navigation and consumer property updates. The component does not persist events, reject overlapping events or perform timezone conversion. No week/month event grid, recurrence, multi-day events, resource lanes, drag/drop or edit-in-place yet.

**GanttChart** extends DataTable. Assign tasks with unique string id, title, inclusive start/end dates, optional progress (0–100, clamped) and dependency IDs. Dates are calendar days, independent of daylight saving time. The range defaults to task bounds or today; rangeStart and rangeEnd override valid bounds. The display is limited to the first 366 days of the chosen range; the timeline column label indicates truncation. Tasks outside the range remain in the table, while partial spans are clipped. Uses ProgressBar within each duration bar. Dependencies are displayed as IDs; no scheduling engine, dependency arrows, critical path, zoom or drag editing. Use tasks, not inherited rows/columns, as the data API. Inherits table sorting, filtering, pagination and context menus. The two components share _schedule.js, which reuses Calendar date arithmetic.

Both are experimental Web Components with standalone package exports, React adapters and direct custom-element property bindings for Vue/Svelte. Browser and accessibility acceptance is still required.
