# Design tools (preview)

- **ThemeEditor** composes ColorPalette, FontPicker, PropertyGrid, Button and Card. Set value to accent, font and radius (0–24 integer px). The accent is normalized to opaque HEX; the themeTokenValues helper maps configuration to the four supported CSS custom properties. The preview applies only those tokens to its subtree. cu-change reports key, value and tokens; reset restores defaults. No global theme mutation, contrast enforcement, persistence or theme-file export.
- **ComponentDesigner** uses DockLayout and PropertyInspector with a fixed allowlist of button, card and text-field descriptors. Each item has a unique ID, type, label, value, disabled and variant (where applicable). Add/remove/select items and edit properties. Preview controls are inert; all strings are assigned via textContent or component properties, not executable markup. Limit 100 items. cu-change reports action, id and items; cu-select reports the selected ID. No arbitrary HTML, nested component hierarchy, drag/drop or source-code generation.
- **WorkflowEditor** uses KanbanBoard for movement, ordering and keyboard alternatives. Assign lanes and items using existing Kanban schemas. Defaults to To do, In progress and Done. Add tasks by title and lane, remove unlocked tasks and move items. readonly prevents mutation. cu-change reports action, id and current items. Lane changes filter tasks to known lanes; data persistence and workflow rules are the host application's responsibility. No automated workflow execution.
- **NodeEditor** uses PropertyGrid, SplitView and ContextMenu. Set value to nodes (unique ID and label) and directed edges (from/to IDs). Invalid or duplicate edges, self-loops and dangling endpoints are discarded; removing a node removes its incident edges. Supports adding/removing nodes, editing labels, connecting/disconnecting nodes, selection and readonly. Bounded to 50 nodes and 200 edges. Cycles are allowed. The current UI is a node and connection list, not a graphical canvas; no draggable ports, edge routing, auto-layout or execution engine. cu-change reports action and value, cu-select reports selection.

These components are preview Web Components with standalone exports and React adapters. Browser and accessibility acceptance remains required.
