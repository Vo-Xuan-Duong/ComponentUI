# Productivity workspace tools (preview)

- **DashboardViewer** renders up to 24 chart descriptors compatible with DashboardDesigner. Search matches all accent-insensitive terms across ID, title and description. cu-filter reports query and visible count; Refresh emits cu-action without fetching. Chart values are consumer-owned. Filtering rebuilds chart instances, so expanded chart data tables are not preserved. No live polling or arbitrary widgets.
- **ProjectWorkspace** uses GanttChart, Scheduler and WorkflowEditor in persistent tabs. The value object contains independent timeline tasks, schedule events, lanes and workItems. date selects a scheduler day. readonly locks schedule and work-item changes, while navigation and table inspection remain available. cu-change reports the updated value and section; cu-navigate reports view/date changes. No automatic synchronization between timeline dates and Kanban stages, critical path, resource allocation or project persistence.
- **SearchWorkspace** normalizes up to 10,000 unique records with id, title, description, category and up to 50 keywords. Search matches all whitespace-separated terms, ignoring case and diacritics including Vietnamese đ. Category is an exact match; empty means all. Results use VirtualList, details are rendered as text, and Open result emits cu-action. Selection is cleared if filtered out. No remote search, relevance ranking, indexing or automatic routing.
- **DocumentManager** uses FileManager and DocumentWorkspace. Supply valid file-tree entries, with optional pre-rendered page URLs and Markdown notes on each file. Selecting a file shows its workspace, preserving edited notes and last visited page for each document in memory. File operations emit requests; readonly locks note editing, not file-operation requests. The host owns authorization, URLs and persistence. Reassigning items replaces note data; page positions survive for retained IDs. No PDF decoding, upload transport, automatic save or filesystem mutation.

All four are preview components. Standalone exports, React adapters, contracts and Playground demos are included. Browser and accessibility acceptance remains required.
