# Console and picker tools (preview)

- **CommandConsole** extends Terminal. Set commands to CommandPalette descriptors. The Commands button or Ctrl/Meta+K while focus is within the console opens the existing palette. Selecting a command submits it through Terminal's existing cu-action event. Command history, output limits and append/clear remain inherited. No shell execution, PTY or ANSI emulation; the host application owns command authorization and execution.
- **KeyboardShortcutEditor** accepts items with unique id, label, shortcut and disabled. Canonical modifier order is Ctrl, Alt, Shift, Meta. Supports letters, digits, F1–F24 and common named navigation/editing keys. Edit by typing a chord or recording supported modified keys/function keys; Escape cancels and Tab navigates. Duplicate assignments are rejected, including conflicts with disabled items. Empty text clears an assignment. cu-change reports id, value, previous and items. The component edits configuration only; it does not register shortcuts or guarantee OS/browser availability. Punctuation, multi-stroke sequences and layout-specific key codes are not supported.
- **ColorPalette** accepts color strings or {value,label} objects. Reuses ColorPicker parsing, canonical HEX output including non-opaque alpha, and color validation. Equivalent colors are deduplicated. Select an existing swatch, choose a custom color, add or remove it. cu-change reports selection; cu-action reports add/remove and colors. No persistent storage, gradient editing or automatic palette generation.
- **FontPicker** accepts a consumer-supplied list of font family strings; defaults to common system/CSS families. Search filters choices while retaining the selected family. The sample attribute customizes preview text. cu-change reports the selected family. It does not enumerate installed fonts, download fonts, validate glyph coverage or guarantee a family is installed; browser fallback applies.

All four reuse the established UI and theme primitives. Browser and accessibility acceptance is still required.
