# Workspace tools (preview)

- **ChartEditor** composes ChartContainer, PropertyGrid and SplitView. Set items to existing chart descriptors and config to title, description, type (bar/line) and showTable. Editing settings or numeric values updates the chart and emits cu-change with key, value, config and items. readonly locks property editing. The existing chart renderer supports up to 100 values. No data-row insertion, multiseries charts, axis customization or export yet.
- **NotificationSettings** exposes a value object with enabled, desktop, sound, email and digest (off/daily/weekly). Uses SettingsPage and shared switches/select. The main switch disables dependent controls without losing preferences; email off disables digest. Reset restores default settings. cu-change reports key and updated value. The component does not request notification permission, send messages or persist preferences.
- **ImageGallery** accepts Carousel descriptors with nonempty src. The active index and loop control navigation. One ImageViewer is reused as the active slide, with shared zoom and rotation reset when its source changes. cu-change reports selection; cu-transform reports zoom/rotation; cu-action forwards image-load state. No image upload, thumbnail grid, download or editing. Image URL lifetime is owned by the application.
- **FileManager** extends FileExplorer and adds CommandBar. The items tree, folder navigation, search, selection and context menu are inherited. selectedEntry returns the selected visible entry. requestAction emits command requests; open navigates folders or emits cu-open for files. Rename/delete/download require selection, download requires a file. New folder/upload/refresh are folder-level requests. The existing context menu emits cu-action for non-open actions. There is no filesystem access, confirmation dialog, upload transport or persistent storage; the application must authorize and implement all operations.

All four are preview Web Components, use existing UI and design tokens, and require browser and accessibility acceptance.
