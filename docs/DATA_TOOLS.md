# Data tools (preview)

**PivotTable** composes DataTable, Select and EmptyState. Set fields (value/label), rows (records), rowField, columnField, valueField and aggregate (count, sum, average, min or max). The optional query property uses QueryBuilder's existing filter engine. Empty dimensions group all records. Count counts records; other aggregates use finite numeric values or numeric strings, ignoring blanks and non-numeric values. Empty numeric buckets produce null. Results include generated columns, rows, grand total, record count and error. Row totals are calculated from original records (not averages of averages). Supports 100 distinct row groups and 30 distinct column groups; larger group sets report an error rather than dropping data. Group fields should contain scalar values. UI changes emit cu-change with config and result. No drag-and-drop pivot layout, multiple measures or nested dimensions yet.

**Spreadsheet** extends DataGrid and uses the shared numeric formula parser. Assign a rectangular matrix through cells; shorter rows are padded. Input is limited to 100 rows and 26 columns (A–Z); larger input is truncated. The default is 8 × 5 when no matrix is supplied. Raw cell values are stored as strings; computedCells provides evaluated results. getCell(address), getComputedCell(address), setCell(address,value) support direct access. Double-click or F2 to edit, Enter to commit, Escape to cancel; DataGrid supplies context actions and pagination. Formula cells begin with = and support arithmetic + - * /, parentheses and references like A1 or B2. Blank references evaluate to 0; text references produce #VALUE!, invalid references #REF!, circular references #CYCLE!, division by zero #DIV/0!, depth limit #LIMIT!, invalid formulas #ERROR!. Expressions are not executable JavaScript. The inherited cu-cell-change event reports the raw changed value. Use cells rather than inherited rows/columns as the worksheet data API. No range functions, copy/paste blocks, formula bar, workbook tabs, drag fill, row/column insertion or Excel import/export yet. Native DataGrid editors are reused; FormulaInput's parser is shared, not a separate formula widget in each cell.

Both are experimental framework-neutral Web Components, with standalone package exports and React wrappers. Vue/Svelte can bind properties on registered elements. Browser, keyboard and accessibility acceptance is still required.
