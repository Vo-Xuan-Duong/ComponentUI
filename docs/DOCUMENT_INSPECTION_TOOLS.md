# Document and inspection tools (preview)

- **PDFViewer**: accepts already-rendered page image URLs through pages, or an application-owned document adapter with pageCount and renderPage(page) returning an image URL or a promise. Assign one source, not both. Uses ImageViewer for zoom and rotation; first/previous/next/last controls navigate 1-based pages. Stale asynchronous render results are ignored. cu-change reports page selection, cu-transform reports image transforms, cu-action reports image-load or render-error. Does not decode PDF bytes, implement text selection, search, annotations, printing or PDF.js integration itself. Consumer manages any generated object URLs and adapter resources. The demo uses synthetic page images, not a parsed PDF.
- **ResourceCalendar**: resources have unique id and label; events use Scheduler's same-day event schema plus resourceId. Events for unknown resources are hidden. Select all resources or one resource and navigate dates. The underlying Scheduler is readonly; the application manages event data and conflicts. No simultaneous resource lanes, drag-and-drop, booking or recurrence. cu-change reports date and resourceId.
- **TimelineEditor**: items use the Timeline item schema with datetime as a valid YYYY-MM-DD calendar date. Entries are sorted by date; edit, add, remove and cancel use existing fields and Timeline. cu-change reports action, id and updated items. readonly prevents user mutations. Does not implement drag reordering, time-of-day editing or automatic dependencies.
- **PropertyInspector**: objects have unique id, label and properties in PropertyGrid's schema. TreeView selects one object; PropertyGrid retains typed editors, filtering and validation. SplitView supplies resizing. cu-select reports object selection and cu-change reports objectId, key, value and previousPropertyValue. readonly prevents user edits. Object hierarchy is flat, and values are explicit descriptors, not live reflection on arbitrary application objects.

All four use existing components and shared theme tokens. Browser and accessibility acceptance is still required.
