# Configuration workspace tools (preview)

- **WorkspaceSettings** combines ThemeEditor, ShortcutSettings and NotificationSettings in persistent tabs. The value property contains theme, shortcuts and notifications; shortcutDefaults supplies reset assignments separately. readonly locks modifications. cu-change identifies the section and includes the complete normalized value. Theme changes remain scoped to the theme preview; no operating-system shortcut registration, notification permissions or persistence.
- **DeveloperTools** exposes lines, commands, logs, request and response through CommandConsole, LogViewer and APIExplorer. append adds console output. Events carry section (console/logs/api); cu-navigate identifies tab selection. disabled locks console and request operations, loading locks API submission. Log inspection remains available. No shell execution, network transport, log collection or sensitive-data redaction.
- **FormBuilder** uses FormDesigner as its single source of truth, generating a readonly structural JSON Schema preview with SchemaEditor. Text, email and textarea map to string, number to number, and checkbox to boolean. Required field names become the schema required list; labels become descriptions. This does not encode email format, nonempty string constraints or checked=true requirements. Native preview FormData contains strings and omits unchecked checkboxes, so it is not directly the typed schema payload. The host must coerce and validate values. cu-action export supplies fields and schema; cu-submit supplies preview data and schema. No reverse schema import, generated source code or real server submission.
- **DataSourceEditor** combines APIExplorer and DataInspector. Set recordPath to a JSON Pointer (empty string for root array; /items for a nested array). RFC 6901 escapes ~0 and ~1 are decoded; only own properties and canonical array indexes are traversed. Extraction accepts JSON arrays and keeps JSON-serializable record objects from the first 1000 array entries; non-records are skipped. The extraction helper rejects bodies over 2,000,000 UTF-16 code units, but the underlying APIExplorer still displays its raw response; this is not a full response-size protection mechanism. Request transport, authorization, credential handling and persistence are host responsibilities. cu-action forwards request descriptors; record inspection and query events are tagged by section. No automatic requests, pagination, live synchronization or writes.

All four are preview components with standalone exports, React adapters and Playground demos. Browser and accessibility acceptance remains required.
