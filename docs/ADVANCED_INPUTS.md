# Advanced inputs (preview)

- MentionInput extends AutoComplete. Provide suggestions with a unique value (a handle without @), label and optional description/disabled. Type @ at the start of text or after whitespace; the current token at the caret filters the shared suggestion popup. Selecting a suggestion replaces that token. The cu-select event contains the full value, mention handle and label. This is single-line input, not a rich text or multiline editor.
- PhoneInput extends TextField. The optional international attribute requires a leading + and 8–15 digits with a nonzero first digit; the default accepts 3–15 digits with optional +. Common separators are accepted. normalizedValue exposes the compact representation; the submitted value remains the original text. This is basic format checking, not country-specific telephone number validation or a country picker.
- QueryBuilder composes DataFilter, Select, Button, IconButton and EmptyState. Assign fields first, then value = {logic:"and"|"or",conditions:[{field,operator,value}]}. Up to 50 flat conditions are supported. Empty conditions are inactive. The filterQueryRows utility uses existing DataTable comparison semantics. No nested groups, SQL generation or remote execution. Not form-associated.
- FormulaInput extends TextField and uses a bounded numeric parser, never JavaScript execution. Supports decimal/scientific literals, unary signs, arithmetic + - * /, parentheses and optional leading =. Expressions are limited to 512 characters and 64 nested calls. result is a number or null; evaluation contains valid/result/error. No spreadsheet references, functions or exact decimal arithmetic.

All four are experimental Web Components using shared design tokens, native form lifecycle where applicable, standalone exports and React mappings. Vue/Svelte can use direct custom-element property bindings. Browser and accessibility acceptance remains required.
