      Framework adapters

      Reuse the same Web Components in React 18/19 and Vue 3. These are source-level integration examples, not runtime previews.

      Experimental · React / Vue

      React integration

      Property synchronization, forwarded refs and native CustomEvent callbacks.

      import * as React from "react";
import { createReactComponents } from
  "@componentui/react";
import "@componentui/web/components";

const { Button, Icon, TextField } =
  createReactComponents(React);

// <TextField value={email}
//   onCuInput={e => setEmail(e.detail.value)} />

      React 18/19 supported by the adapter API; browser integration still needs local validation.

      Vue integration

      Compile-time Custom Element recognition with a controlled-value directive.

      import { isComponentUIElement } from
  "@componentui/vue";

// Vite plugin-vue config:
vue({ template: { compilerOptions: {
  isCustomElement: isComponentUIElement
}}})

// Register ComponentUIVuePlugin
// <cu-text-field v-cu-model="model" />

      Vue 3 requires build-time configuration when using SFC templates.

      Current scope: The framework adapters remain experimental. The HTML Playground shows integration snippets; it does not execute React, Vue or Svelte. See framework adapter documentation for complete examples and limitations.
